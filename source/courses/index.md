<section id="overview" class="active">
<h2>总述</h2>
<p>Courses 用于存放课程设计报告，以及一些课程的课件。</p>
</section>
<section id="electronic-circuits">
<h2>电子电路基础</h2>
<h3>课程概览</h3>
<p>课程内容分为电路原理和模拟电子技术两大部分。电路原理部分涉及基尔霍夫电压定律和电流定律、电路等效变换、正弦稳态电路分析等，其中电路复矢量分析方法在后续电磁场与电磁波课程中会再次涉及。模拟电子技术部分涵盖半导体器件基础、基本放大电路、多级放大电路、集成运算放大器、反馈、功率放大电路等。英文班课件资料已放入资源入口，习题网站由任课教师提供。</p>
<h3>专题研究</h3>
<p>专题研究任务需要完成一个仪表放大电路的应用设计，包含电路原理分析、参数计算和仿真验证。</p>
<iframe class="pdf-preview" src="/courses/resources/电子电路基础/仪表放大电路应用及设计专题研究报告.pdf" title="仪表放大电路应用及设计专题研究报告预览"></iframe>
</section>
<section id="digital-system-design">
<h2>数字系统设计</h2>
<h3>课程概览</h3>
<p>课程内容包含数制与编码、逻辑代数基础、组合逻辑电路分析与设计、时序逻辑电路分析与设计、脉冲波形产生与整形、半导体存储器、可编程逻辑器件等。</p>
<h3>实验部分</h3>
<p>数电实验单独设课，使用 Verilog HDL 进行电路设计与仿真验证，实验内容涵盖组合电路模块设计、时序电路设计和综合应用，教材对实验步骤有详细说明。实验代码与报告后续更新至 Project 版块。</p>
</section>
<section id="signals-and-systems">
<h2>信号与系统</h2>
<h3>课程概览</h3>
<p>课程涵盖连续时间信号与系统的时域和频域分析、傅里叶级数、傅里叶变换、拉普拉斯变换、Z 变换、离散时间信号与系统分析等内容。采样定理为课程重点章节，涉及奈奎斯特采样定理、混叠现象、信号重构等内容。</p>
<h3>专题研究</h3>
<p>专题研究选题由任课教师提供，涵盖不同方向。选题是基于矩形窗的短时傅里叶变换实现与音频时频分析，包含算法原理、MATLAB 实现和结果分析。</p>
<iframe class="pdf-preview" src="/courses/resources/信号与系统/基于矩形窗的短时傅里叶变换实现与音频时频分析.pdf" title="基于矩形窗的短时傅里叶变换实现与音频时频分析预览"></iframe>
</section>
<section id="electromagnetic-fields">
<h2>电磁场与电磁波</h2>
<h3>课程概览</h3>
<p>课程内容包含矢量分析、传输线理论、麦克斯韦方程组、平面电磁波、电磁波的反射与透射、波导与谐振腔等。教材内容体系完整但篇幅较大，课堂教学包含详细板书推导。</p>
<h3>专题研究</h3>
<p>专题研究选题由老师给定，内容涉及公式推导、MATLAB 编程与仿真软件使用。选题是用 MATLAB 程序解决双枝节匹配问题。</p>
<iframe class="pdf-preview" src="/courses/resources/电磁场与电磁波/双枝节匹配问题.pdf" style="height: 450px;"></iframe>
<h3>实验部分</h3>
<p>课程另有四次实验课，实验报告后续更新至 Project 版块。</p>
</section>
<section id="isee-introduction">
<h2>信息与电子工程导论</h2>
<h3>课程概览</h3>
<p>课程内容包括信息论基础、通信系统概述、信号与系统初步、编码理论等。</p>
<h3>课程设计</h3>
<p>课程设计任务是在面包板上搭建一个四位加法器电路，使用三极管实现逻辑门功能，包含电路方案设计、面包板搭建与功能测试。</p>
<iframe class="pdf-preview" src="/courses/resources/信息与电子工程导论/课程设计+第11组.pdf" title="课程设计+第11组预览"></iframe>
<h3>实验部分</h3>
<p>另有三次小实验，涵盖信号频谱分析、信号调制仿真和三极管特性仿真，实验报告后续更新至 Project 版块。</p>
</section>

<h3>课程概览</h3>
<p>课程内容涵盖搜索算法、对抗搜索、机器学习、深度学习基础等。</p>

<h3>实验部分</h3>
<p>实验部分包含三次任务：八数码问题、井字棋与对抗搜索、Fashion-MNIST 子集分类任务，实验报告后续更新至 Project 版块。</p>
<h3>课程设计</h3>
<p>课程设计为自主选题，要求完成实验设计、代码实现与结果分析，可选课题包括上课内容相关题目或开源项目复现与改进。完成了基于深度学习的 IMDB 影评情感分类项目，报告如下。</p>

<h2>离散数学</h2>
